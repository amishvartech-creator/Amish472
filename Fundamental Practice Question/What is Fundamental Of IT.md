# What is a Computer ?

A computer is an electronic device that processes data.

**Examples**

1. receives input

2. performs calculations and logic

3. stores and retrieves information

4. outputs result


# Explain the difference between hardware and software ?

1. Hardware is the physical parts of a computer system you can touch.

2. Software is the set of programs and instructions that tell the hardware what to do.

In short:
- hardware = physical components
- software = instructions and programs running on that hardware

# What are the different types of Software ?

1. Intangible: You cannot touch software; it is the logic and instructions, not the physical machinery.

2. Instructions: It instructs the CPU, memory, and peripherals to function.

3. Bridge: It bridges the gap between human needs and machine capabilities.

4. Types: Major categories include System Software (e.g., Operating Systems like Windows or Linux), Application Software (e.g., Microsoft Word, web browsers), and Programming Tools


# What is an operating system ?

An operating system is system software that manages computer hardware and provides services for applications.

It:
- controls the CPU, memory, storage, and devices
- manages files and security
- provides a user interface
- allows applications to run


# Name any five operating system ?

**Windows, macOS, Linux, Android, iOS**


# What is RAM ? How is it different from ROM ?

1. RAM is temporary memory that the computer uses while it is running programs.

2. ROM is permanent memory that stores firmware or startup instructions.

Key differences:

1. RAM is volatile: data is lost when power is off.
2. ROM is non-volatile: data remains when power is off.
3. RAM is used for active data and programs.
4. ROM is used for boot firmware and fixed system code.

# What is a CPU ? Explain its main components.

A CPU is the central processing unit, the main chip that executes instructions and performs calculations.

Main components:

1. Control Unit (CU): fetches and decodes instructions, directs other parts.

2. Arithmetic Logic Unit (ALU): performs arithmetic and logic operations.

3. Registers: small fast storage for immediate data and instructions.

4. Cache: very fast memory for frequently used data/instructions.


# What is the function of the motherboard ?

The motherboard is the main circuit board that connects and allows communication between all computer parts.


# What is an IP address ?

An IP address is a unique numerical label assigned to each device on a network so it can send and receive data.


# What is the difference between LAN,MAN and WAN ?

**LAN**

 (Local Area Network): network in a small area like a home, office, or school. Fast speed, limited geographic range.

**MAN**

 (Metropolitan Area Network): network that covers a city or campus. Larger than LAN, smaller than WAN.

**WAN**

 (Wide Area Network): network covering a large geographic area, often connecting cities or countries. Slower than LAN/MAN and uses public or leased communication links.


# What is cloud computing ?

Cloud computing is using remote servers on the internet to store, manage, and process data instead of using a local computer

# what is database ?

A database is an organized collection of data stored so it can be easily accessed, managed, and updated.

It:

1. stores information in tables or structured formats

2. lets users search, add, change, and delete data

3. is used by applications to keep records like customers, products, or transactions

# What is the difference between primary storage and secondary storage ?

Primary storage:

1. also called main memory or RAM

2. is fast and directly accessible by the CPU

3. stores data and programs while the computer is running

4. is usually volatile (loses data when power is off)

Secondary storage:

1. also called auxiliary or external storage

2. is slower and not directly accessed by the CPU

3. stores data permanently or long-term

4. examples: hard drives, SSDs, USB drives, optical discs


# What is a firewall ?

A firewall is a security system that monitors and controls incoming and outgoing network traffic.


# What is antivirus soatware ?

Antivirus software is security software that detects, prevents, and removes malicious programs (viruses, trojans, worms, ransomware, spyware).


# Explain the difference between compiler and interpreter ?

1. A compiler translates the entire source code into machine code before the program runs.

2. An interpreter translates and executes code line by line at runtime.

**Key differences:**

1. Compilation is done once up front, while interpretation happens every time the program runs.

2. Compiled programs usually run faster, while interpreted programs are easier to test and change quickly.

3. A compiler produces an executable file, while an interpreter does not produce a separate machine-code file.


# What is the difference between the Internet and the World Wide Web ?

1. The Internet is the global network of connected computers and devices.

2. The World Wide Web (WWW) is a service that runs on the Internet and uses web pages and links.

In short:

- Internet = network of networks.
- World Wide Web = system of websites and web pages accessed through the Internet.

# What is phishing ?

1. Phishing is a type of online scam where attackers pretend to be a trusted person or company.

2. It is used to trick people into giving sensitive information like passwords, bank details, or credit card numbers.


# Explain the booting process system of computer ?

1. Booting is the process a computer uses to start up and load the operating system.

2. When power is turned on, the computer first runs a small program stored in ROM called BIOS or UEFI.

3. BIOS/UEFI checks the hardware components (power-on self-test, or POST) and finds the boot device.

4. It then loads the operating system kernel from storage into RAM.

5. Finally, the operating system starts up services and makes the computer ready for use.

In short:

- Power on → BIOS/UEFI startup → hardware check (POST) → load OS into memory → OS initializes.
